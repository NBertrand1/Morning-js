# Morning JS — JavaScript Learning Lab

**Collection de mini-projets JavaScript | JavaScript mini-project collection**

## Français

Ce dépôt rassemble des exercices et mini-projets réalisés pour renforcer les fondamentaux de JavaScript et pratiquer la manipulation du DOM, les événements, le stockage local et les appels à des API.

### Accéder aux exercices

Une page d'accueil permet de parcourir les mini-projets : ouvrez `index.html` à la racine du dépôt ou servez le dossier avec un serveur statique local.

### Mini-projets présents

- Toast Notifications
- Bibliothèque
- Classes JavaScript
- Convertisseur de devises
- Crypto Board
- EcoDon
- Générateur de profil
- GitHub Profile Analyser
- Joke App
- Movie Explorer
- Playlist Manager
- Todo avec LocalStorage
- Weather App

### Lancer localement

Vous pouvez ouvrir `index.html` dans un navigateur. Pour les exercices qui utilisent des API externes, une connexion Internet et, selon le service, une clé API peuvent être nécessaires.

### État du dépôt

Il s'agit d'un laboratoire d'apprentissage composé de mini-projets indépendants, et non d'une application unique prête pour la production. Les exercices devront être testés individuellement et certains nécessiteront une mise à jour de leurs API ou de leurs interfaces.

## English

This repository contains JavaScript exercises and small projects created to strengthen core JavaScript skills and practice DOM manipulation, events, local storage, and API requests.

Open the root `index.html` to browse the mini-projects. Some API-based exercises may require an Internet connection and, depending on the service, an API key.

This is a learning lab made of independent mini-projects, not a single production-ready application. Each exercise should be tested individually; some may need API or interface updates.
